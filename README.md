## How I approach my labs

- Build a small, clearly defined environment.
- Test the outcome instead of stopping at resource creation.
- Record problems and the steps that resolved them.
- Distinguish completed tests from planned improvements.
- Keep credentials and private infrastructure details out of public documentation.

I'm continuing to develop my cloud and systems administration skills, one documented project at a time.
